# Política de seguridad

## Reportar una vulnerabilidad

No publiques detalles explotables en una incidencia pública. Usa la función **Security advisories** del repositorio de GitHub o contacta de forma privada con el mantenedor.

Incluye una descripción, pasos de reproducción, impacto estimado y, si existe, una propuesta de mitigación. Se intentará confirmar la recepción en un plazo de 72 horas.

## Alcance

HeaderGuard es una herramienta educativa, no un sustituto de una auditoría profesional. Escanea únicamente sistemas propios o para los que tengas autorización.
